# Boiler district artwork

Created using the built-in imagegen tool for the requested Medium robot and isometric boiler district remake. Original ship artwork is unchanged. PNG alpha is retained; the engine uses atlas regions without destructive slicing.

Assets: `art/characters/medium_v2/directions.png`, `art/boiler/chamber.png`, `art/boiler/machinery_and_enemies.png`.
