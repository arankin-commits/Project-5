# Flying Liberty — 16 Original Lobby Themes (v1)

16 instrumental themes for the Flying Liberty flying ship hub.

## Production concept

**Historical / classical fantasy (tracks 01–08):** combines Renaissance-inspired modal counterpoint, imitation, and dance types with Victorian/Romantic parlour instrumentation, warm chamber music and brass. This is an intentional fantasy fusion: historical Renaissance (c. 1400–1600) and Victorian (1837–1901) were NOT the same era.

**New Age / neo-Renaissance fantasy (tracks 09–16):** modern reimagining of those timbres with extended/suspended modal sonorities, repeating figures, spacious sustained textures and digital pad timbres. New Age is modern, not an actual Renaissance period style.

The recurring original *Flying Liberty* leitmotif is a short six-degree arch (1–2–4–5–4–2, adapted to each track's mode). It appears in different keys, octaves, tempi, harmonies, and note lengths. This is an original phrase, not a quotation of a historical composition.

## How to listen

`Audio/<track>/Listen_Quiet_Lobby.mp3` — ordinary lobby playback.

`Audio/<track>/Dynamic_Layer_Demo.mp3` — first 7 sec quiet, gradually adds layers over the next 6 sec, last 7 sec full.

`Previews/Classical_8_Track_Sampler.mp3` and `Previews/New_Age_8_Track_Sampler.mp3` — eight short excerpts per volume.

## Files

For each track: four **OGG stems** `Foundation.ogg`, `Theme.ogg`, `Counterpoint.ogg`, `Atmosphere.ogg`; two prepared OGG loops (`Quiet_Lobby_Loop.ogg` and `Full_Story_Loop.ogg`); MP3 listen preview and dynamic-layer demo; five MIDI compositions (full + four parts).

All four stems within each track are **identical exact sample lengths and start together**. Different tracks have different lengths/meter and are not intended to play in sync with each other. The OGG files are intended to loop inside Godot. Disable cross-track beat-synced switching unless you add a transition manager.

For Godot 4, copy `Audio/` into your game's assets and add the included script `Godot/LobbyMusicDirector.gd` as an autoload. Change `audio_root` to the actual res:// path; call `play_track("01_Copper_Hearth")` or `set_story_focus(true/false)`.

The Godot code is a starting integration example; engine runtime is **not** tested here.

## Music sourcing / rights

All MIDI compositions are originally generated for this soundtrack using the bundled editable Python script and do **not** use protected songs or melodies. The MP3/OGG audio was rendered with the installed **TimGM6mb.sf2 General MIDI SoundFont**. That sample bank is third-party and is **not included**. Please verify the SoundFont's original redistribution/commercial licensing and consider re-rendering the MIDI with a clearly licensed commercial sample library before publishing a paid game. These are synthesized performances, not acoustic or live-orchestra recordings. "Concertina" is approximated using the accordion GM patch, "cornet" using trumpet, and the specific historical piano types by GM acoustic piano patches.

The audio used a fixed 24 kHz stereo output for a practical game asset size. MIDI allows re-rendering at higher quality and with upgraded instrument libraries. No music generated by directly mimicking a named contemporary artist.

## Audio / data checks

`track_manifest.json` records musical meter, BPM, key/mode, chosen instruments, note counts, sample counts, and length. Verify any game loop seams and balance levels in your Godot test scenes. Sample-aligned stems permit vertical layering; the encoding is Ogg Vorbis, so decoded audio may have tiny codec-tail differences depending on the playback implementation.
