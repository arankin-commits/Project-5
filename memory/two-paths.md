# Two Paths

## Fact or rule

The game has two paths with different objectives:

- **Going up — Above-ground route:** Confront the top brass.
- **Going down — Underground route:** Investigate tech.

Above-ground progression, from start to end:

1. Storage (Start)
2. Flying Ship gallery
3. Executive
4. Summit Chambers (End)

Underground progression, from start to end:

1. Maintenance (Start)
2. Factory
3. Boiler
4. Toxin Refinery (End)

## Why

The user established these two routes, their objectives, and their area order as durable project decisions.

## How to apply

Use these objectives and start-to-end sequences when planning or changing route selection, area progression, maps, or story content. This note records intended design, not verified implementation.
