ELEMENTAL ABILITY ANIMATION REFERENCE PACK
=========================================

OPEN: Elemental_Ability_Animation_Lab.html in a modern browser to preview, loop, pause and choose all 65 elemental cards.

Animations/<Element>/<Card>.gif: 65 individual looping, 480x270 concept VFX previews matching the mechanical roles of the card definitions.
Status_References/: six individual visual status examples (Burn, Wet, Rust, Frost, Freeze, Stagger) plus the source reference sheet.

SOURCE: Pasted markdown(2).md supplied in the conversation. Ability stats displayed in the interactive viewer come from the supplied document.

IMPORTANT: These are animation reference concepts and demonstrations. They are NOT rigged characters, transparent spritesheets, production-ready Unity/Godot effects, or executable implementations of game rules.
Some static status illustrations contain illustrative shorthand; use the original rule document as the authoritative specification.

CONTROLS: click an elemental tab and then a card; press Space to replay; use Left/Right arrows to change card; number keys 1-6 to switch elements.
